Appearance

A look is how the desk is drawn: its sky or its paper, what moves on it, and the colours it brings. Looks are grouped by genre — the weather, paper, a coach's board — and every look has a light and a dark side: the toggle beside the picker switches between them, and Auto follows the system's appearance. The palette a look is drawn on is written to the same ~/.agentdata/config.json that ad-theme set writes, so this project's terminal prompt and tab follow it. A look under Plain is a palette on its own: the plain page in that colour.

The tiers are the widths at which a pane on the desk changes what it draws: a rail, then compact, then full. They start at the numbers CI measures against; set the laptop's here once you have tried them on the real monitors, and every open desk redraws at once (docs/desk-window.md §The tiers).

Model per agent

What each agent is launched with, pressed rather than typed. On CLI default, no --model flag is passed at all and the Copilot CLI picks for itself — which is the only no-model behaviour anyone has measured, so it is the one this uses. A change takes effect on the agent's next turn: the command line is fixed when the process starts.

What an agent may run

Read-only here, deliberately. The allow-list is the boundary and configuration replaces it rather than adding to it, so a list saved from this page would become the whole boundary — and you would silently stop receiving any command a later version adds. Change it in ~/.agentdata/config.json or through ad-setup, where the whole list is in front of you. The deny-list is a floor: configuration can add to it and can never remove one of these.
