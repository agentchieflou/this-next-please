# Code Graph

The code graph subsystem provides static analysis, symbol indexing, repository mapping, and guarded optimizations.

## Layout under `.agent/graph/`

| File | Purpose |
|---|---|
| `graph.json` | Complete deterministic graph: all nodes and edges sorted by id/keys. |
| `meta.json` | Graph metadata: root relpath, file count, extractor counts, sha256 hash, and file fingerprints. |
| `understanding.md` | Human-readable explanation generated by `ad-graph explain` / `codebase-map`. |
| `approval.json` | Human approval stamp produced by `ad-graph approve`. |
| `coverage.json` | Test coverage data mapped per node produced by coverage collection. |

## Node Kinds

- **`file`**: Source files (e.g. `agentdata/cli_graph.py`).
- **`class`**: Defined classes (e.g. `agentdata/graph/model.py::Graph`).
- **`function`**: Functions or class methods (e.g. `agentdata/graph/builder.py::build_graph` or `agentdata/graph/model.py::Graph.add_node`).
- **`test`**: Test functions or test methods (e.g. `tests/test_graph.py::test_build_graph`).

Each node carries:
- `id`: Canonical identifier.
- `where`: Line range `path:start-end`.
- `sha`: SHA-256 hash of the node's source slice.
- `loc`: Lines of code.
- `complexity`: Cyclomatic branch complexity.
- `tags`: Special classifications such as `entrypoint` or `io`.

## Edge Kinds

- **`defines`**: File defines class/function, class defines method.
- **`contains`**: Class contains method.
- **`imports`**: File/module imports another module (`ext:<name>` or in-repo file path).
- **`calls`**: Function calls function/method (statically resolved or `unresolved:<name>`).
- **`tests`**: Test node tests symbol (derived from name heuristic or coverage contexts).

## Commands

- `ad-graph build [<root>] [--out .agent/graph] [--force]`: Extracts deterministic graph into `.agent/graph/`.
